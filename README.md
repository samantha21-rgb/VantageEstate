
# VantageEstate

**Where Vision Meets Value**

VantageEstate is a real estate website focused on property opportunities in Nairobi, Kenya.

## Website Pages

- Home — `index.html`
- Properties — `properties.html`
- Property Details — `property-single.html`
- Our Story — `about.html`
- Services — `services.html`
- Our Experts — `agents.html`
- Contact — `contact.html`
- Service Details — `service-details.html`
- Starter Page — `starter-page.html`

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Project Structure

- `assets/` — Stylesheets, scripts, images, and vendor resources
- `forms/` — Contact form resources

## Project Purpose

The website provides a branded interface for exploring property listings and real estate services in Nairobi.

## Status

The website pages have been customized and uploaded to GitHub. Further testing and deployment checks may still be required.
